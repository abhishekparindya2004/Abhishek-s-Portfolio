HOSTING REQUIREMENTS
• PHP 8.0 or newer
• The folders data/ and uploads/ must be writable by PHP (usually permission 755 or 775).
• Upload every file and folder together. Do not open index.html directly with file://.
• Open the website through your hosting URL or a local PHP server.

GALLERY FIXES
• Uploaded gallery images are saved as real files in uploads/gallery/.
• JPG, PNG, WebP and GIF are supported.
• HEIC images must be converted to JPG, PNG or WebP first.
• Images are resized/compressed in the browser before upload where appropriate.
• Duplicate gallery entries are filtered in both JavaScript and PHP.
• Cards float gently inside reserved gallery spacing and do not cover other sections.
• Clicking a gallery card opens a full-image preview.
• Image URLs must use HTTPS when the website itself uses HTTPS.

IMPORTANT
Free static-only hosting such as GitHub Pages cannot run api.php. Use PHP hosting for shared updates across devices.
